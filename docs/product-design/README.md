# HireProof Product Design

This folder is the public-safe design archive for HireProof's product review work. It keeps the Figma overview exports, responsive product screenshots, and capture metadata together for future product, UI, and case-study review.

## Contents

- [screens/](screens/) - exported product screens and Figma overview renders.
- [screens/README.md](screens/README.md) - human-readable archive index with viewport, route, and Figma QA notes.
- [screens/_manifest.json](screens/_manifest.json) - machine-readable capture manifest.

## Start Here

Review these overview exports first:

- [00 Preview](screens/00-preview.png) - portfolio-style file cover.
- [02 Design System](screens/02-design-system.png) - foundations, tokens, components, patterns, and documentation overview.
- [03 Product Strategy](screens/03-product-strategy.png) - product planning, decisions, outcomes, and learnings.

Then use the responsive route screenshots in [screens/README.md](screens/README.md) for mobile, tablet, and desktop product review.
